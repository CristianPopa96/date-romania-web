# Glossary

Romanian words and acronyms you meet on the site, with what they mean here.

## Institutions and data sources

| Term                        | Meaning                                                                                                                         |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **SEAP** / **SICAP**        | Romania's electronic public procurement system (e-licitatie.ro), run by ADR. The main source of contracts and direct purchases. |
| **ADR**                     | Autoritatea pentru Digitalizarea României, which runs SEAP and publishes its quarterly contract exports on data.gov.ro          |
| **data.gov.ro**             | The national open data portal                                                                                                   |
| **MDLPA**                   | Ministerul Dezvoltării, Lucrărilor Publice și Administrației, the ministry that runs the Anghel Saligny programme               |
| **Anghel Saligny (PNIAS)**  | A national investment programme paying town halls for roads, water, sewage and gas works                                        |
| **ANAF**                    | The national tax agency; its data (county, locality, company status) is not collected yet                                       |
| **Forexebug**               | The treasury's budget execution reporting system; not collected yet                                                             |
| **MIPE**                    | The ministry for EU funds; not collected yet                                                                                    |
| **TED**                     | The EU's Official Journal tenders database; not collected yet                                                                   |
| **Primăria**                | Town hall                                                                                                                       |
| **Consiliul Județean**      | County council                                                                                                                  |
| **Autoritate contractantă** | Contracting authority: the public body that buys                                                                                |

## Identifiers

| Term     | Meaning                                                                                                                                                           |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **CUI**  | Cod unic de înregistrare, the tax ID of an institution or a company. It is the "spine" of the site: every page of an institution or a company is addressed by it. |
| **CNP**  | Cod numeric personal, a person's ID number. Masked as `[CNP]` on the site.                                                                                        |
| **CPV**  | Common Procurement Vocabulary, the EU code for what was bought (for example 45 for construction works)                                                            |
| **SMIS** | The code of an EU-funded project                                                                                                                                  |
| **PFA**  | Persoană fizică autorizată, a sole trader                                                                                                                         |

## Procurement words

| Term                               | Meaning                                                                                                                                              |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Achiziție directă**              | Direct purchase: a small purchase without an auction, under a legal ceiling (270,120 lei for goods and services, 900,400 lei for works, without VAT) |
| **Anunț de atribuire**             | Award notice: the SEAP notice that publishes who won a procedure. It can hold several contracts.                                                     |
| **Anunț de participare**           | The notice that opened the procedure                                                                                                                 |
| **Contract obișnuit**              | An ordinary contract                                                                                                                                 |
| **Acord-cadru**                    | Framework agreement: a ceiling for future purchases, not money spent                                                                                 |
| **Contract subsecvent**            | A subsequent contract signed under a framework agreement: the money actually committed                                                               |
| **Asociere**                       | Association: several companies winning one contract together                                                                                         |
| **Câștigate singur / în asociere** | Contracts won alone / as part of an association                                                                                                      |
| **Ofertă acceptată**               | Accepted offer: the only direct purchase state counted as money spent                                                                                |
| **Plafon**                         | Ceiling, the legal limit of a direct purchase                                                                                                        |
| **Fără TVA**                       | Without VAT                                                                                                                                          |
| **Furnizor**                       | Supplier                                                                                                                                             |
| **Cumpărător**                     | Buyer                                                                                                                                                |
| **Constructor / Proiectant**       | Builder / designer (of an Anghel Saligny project)                                                                                                    |

## Labels on the site

| Label                                      | Meaning                                                               |
| ------------------------------------------ | --------------------------------------------------------------------- |
| **Nepublicat**                             | The source does not publish this value                                |
| **Încă necolectat**                        | The source publishes it; not collected yet                            |
| **Legătură sigură / probabilă / posibilă** | Sure / probable / possible link between two records                   |
| **Listă incompletă**                       | The list is incomplete (contracts appear in SEAP weeks after signing) |
| **Peste plafon · nu intră în total**       | Published above the legal ceiling; left out of totals                 |
| **Neacceptată · nu intră în total**        | Not accepted; left out of totals                                      |
| **Tipar observat, nu o acuzație**          | An observed pattern, not an accusation                                |
| **Sursa: … · preluat …**                   | Source: … · read on …                                                 |
| **De unde e cifra asta?**                  | "Where is this figure from?", the source panel of one record          |
| **Clasamente**                             | Rankings                                                              |
| **Tipare**                                 | Patterns                                                              |
| **Surse**                                  | Sources                                                               |
| **Metodologie**                            | Methodology                                                           |
| **Corecturi**                              | Corrections                                                           |
| **Raportează o eroare**                    | Report an error                                                       |
| **Drumul banilor**                         | "The road of the money", the chain on a programme project page        |
